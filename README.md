# Glitch Maker

動画に **データモッシュ（Iフレーム欠落）** や **マクロブロック（低ビットレート／パケットロス）** のグリッチを、
フレーム単位で狙ってかけられるブラウザアプリです。PC・スマホの両方で動作し、処理はすべてブラウザ内で完結します
（動画がサーバーへ送信されることはありません）。

## 公開方法（GitHub Pages）

ビルド不要の静的サイトなので、リポジトリをそのまま公開できます。

1. このブランチを `main` にマージする（またはPagesの公開元にこのブランチを選ぶ）
2. GitHub のリポジトリ画面 → **Settings → Pages**
3. **Build and deployment → Source** を「Deploy from a branch」にする
4. Branch を `main`、フォルダを `/ (root)` にして **Save**
5. 数十秒後に `https://<ユーザー名>.github.io/glitch_maker/` で使えるようになります

ローカルで試す場合は、任意の静的サーバーで配信してください（`file://` では ES Modules / Worker が動きません）。

```sh
npx http-server . -p 8080
# または
python3 -m http.server 8080
```

## 使い方

1. **開く** から動画を選ぶ（ドラッグ＆ドロップも可）。処理解像度と読み込む範囲を選んで読み込みます。
2. シークバーやボタンで、グリッチを始めたいフレームへ移動します。
3. **エフェクト追加** → 現在のフレームからエフェクトが始まります。
   開始・終了は「現在位置」ボタンでいつでも付け替えられます。
4. **お試し再生** で結果を確認。停止すると元のフレームへ戻ります。
5. **書き出し** で MP4（非対応ブラウザは WebM）として保存。元の音声も含められます。

### フレーム操作

| 操作 | 内容 |
| --- | --- |
| シークバーを左右ドラッグ | フレーム移動 |
| 押したまま **上へ** / **下へ** | シークバーの拡大 / 縮小（指の下のフレームは固定されたまま） |
| ピンチ・マウスホイール | 拡大 / 縮小 |
| 横スクロール・Shift+ホイール | 表示範囲の移動 |
| ダブルクリック / ダブルタップ | 全体表示 |
| 上部の細いバー | 全体の中での表示範囲。タップでジャンプ |
| `≪≪≪ 30` `≪≪ 10` `‹ 1` ボタン | 30 / 10 / 1 フレーム戻る（長押しで連続） |
| `▶` 再生 | 再生した位置がそのまま選択フレームになる |
| `↺▶` お試し再生 | 選択フレームは変えずにプレビュー。停止で元の位置へ |
| フレーム番号欄 | 番号を直接入力してジャンプ |

キーボード: `Space` 再生、`Enter` お試し再生、`←/→` 1f、`Shift+←/→` 10f、`Alt(Ctrl)+←/→` 30f、
`Home/End`、`+ / - / 0` シークバー拡大・縮小・全体、`[ / ]` 選択レイヤーの開始・終了を現在位置に。

### レイヤー

- エフェクトは何枚でも重ねられます。下のレイヤーから順に適用され、上のレイヤーは下の結果に対してかかります。
- 目のアイコンで一時的にオフ、矢印で順番入れ替え、複製・削除ができます。
- 各レイヤーに開始／終了フレームと不透明度があります。

## エフェクト

### データモッシュ（Iフレーム欠落）

ブラウザ内に小さな「動画コーデック」を実装し、実際のエンコーダ／デコーダと同じ処理
（16×16 マクロブロックの動き推定・動き補償・8×8 DCT による残差の量子化）を再現しています。

- **Iフレーム欠落**: 開始フレームのIフレームが失われたものとして、デコーダは古い絵を持ち続けます。
  以降のPフレームの「動きベクトル」と「差分（残差）」だけが古い絵に積み重なり、
  前のシーンが新しいシーンの動きで引きずられ、新しいシーンの輪郭がゴーストのように浮かびます。
  - 参照フレーム: 通常は開始直前のフレーム。別の場面を指定すると、その絵に動きを乗せられます。
  - イントラ復帰: 大きく動いた部分（エンコーダがイントラ符号化するブロック）だけ本来の映像に戻ります。
- **Pフレーム複製（ブルーム）**: 開始フレームの動きを繰り返し適用し、映像が溶けるように流れます。
- 残差の強さ、動きベクトル倍率、マクロブロックサイズ、量子化（画質）を調整できます。

### マクロブロック／パケットロス

- **ビットレート（画質）**: 低くすると圧縮ブロックノイズ（4:2:0 の色にじみ含む）。
- **パケットロス率 / 欠け方**: スライス単位・ブロック単位・フレーム末尾まで、の3種類。
- **欠けた部分**: 動きで引きずる／前フレームのまま／ずれ／ブロックノイズ／緑（YUV=0）／グレー。
- **エラー伝搬**: 次のキーフレームまで崩れが残り、動きに合わせて広がります。
- 乱数はシード固定なので、何度再生しても同じ結果になります。

## 技術メモ

- 動画の読み込み・書き出し: [Mediabunny](https://mediabunny.dev/)（WebCodecs）。
  WebCodecs が使えない形式はブラウザの `<video>` を使った互換モードで読み込み、
  書き出しは MediaRecorder にフォールバックします。
- 読み込んだフレームは処理解像度で JPEG としてメモリに保持し、フレーム単位で正確にシークできます。
- グリッチは前のフレームの状態に依存するため、描画は Web Worker 上で順番に計算します。
  途中状態のチェックポイントと描画済みフレームのキャッシュ（シークバー下の緑の線）で、
  前後へのシークを高速化しています。書き出し時はキャッシュを使わず再計算します。

### ファイル構成

```
index.html              画面（アイコンは SVG スプライト）
css/style.css
js/main.js              アプリ本体（状態・再生・読み込み・書き出しUI）
js/timeline.js          拡大縮小できるシークバー
js/layers-ui.js         レイヤー一覧とパラメータ編集
js/loader.js            動画の解析とフレーム取り出し
js/exporter.js          動画の書き出し
js/renderer.js          描画 Worker とのやり取り
js/effects/defs.js      エフェクトの定義（パラメータ・既定値）
js/worker/codec.js      コーデックの簡易シミュレータ（動き推定・DCT など）
js/worker/fx.js         各エフェクトの実装
js/worker/engine.js     レイヤーの順次処理・チェックポイント・キャッシュ
vendor/mediabunny.min.mjs  (MPL-2.0, vendor/mediabunny.LICENSE)
```

### エフェクトを追加するには

1. `js/effects/defs.js` の `EFFECTS` に定義（表示名・色・パラメータ）を追加し、`EFFECT_ORDER` に並べる
2. `js/worker/fx.js` に `observe / process / reset / snapshot / restore / stateBytes` を持つクラスを実装し、`IMPL` に登録する

パラメータ編集UIは定義から自動生成されます（`range` / `select` / `bool` / `frame` / `seed`）。

## 動作環境

最新の Chrome / Edge / Safari（16.4 以降）/ Firefox。動画のコーデックはブラウザが対応しているもの
（MP4(H.264)、MOV、WebM など）が読み込めます。長い動画や高解像度ではメモリを多く使うため、
読み込み時に範囲や処理解像度を調整してください。
